## Assignment summary

**Task 1 — Write the test cases.** Identify flows worth automating across Deskline (UI)
and the Library Management API. Target 2–3 UI cases and 3–4 chained API cases. Review
the list with the lead before automating.

**Task 2 — Automate.** Research UI and API automation tooling, automate the approved
cases, then demo a live run.

There is a review gate between the two tasks. Nothing in this folder is automated yet —
these documents are the Task 1 deliverable.
